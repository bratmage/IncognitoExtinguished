# IncognitoExtinguished
Incognito Resurrected backport to wotlk 3.3.5 environments.

## Identify yourself in chats- a faceless alt, you are no more!

###  Features:
- Use /inc to open customization menu
- Customizable name tag that can get added to almost any channel
- Disable the name tag if character name matches the name tag
- Selectable enabling per channel- my top recommendation is /g!

**Incognito**- an addon for 3.x wotlk.

**IncognitoResurrected**- a reboot of incognito for retail environments.

**IncognitoExtinguished** - The resurrected updates, coming back home to 3.3.5.
